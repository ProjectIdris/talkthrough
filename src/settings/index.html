Talkthrough settings

Saved to your settings file. Changes take effect when Talkthrough is restarted, except the list of windows to skip, which works at once.

More detail

When you ask for more detail, a stronger model redraws what is on screen in finer detail. It uses more of your allowance and only runs when you ask.

Voice

The words of each spoken step are sent to this address, and nothing else. If it is down or slow, the system voice speaks instead.

Hearing

Where your question is turned into text. Your recording is sent there, so it should be on this computer. Empty: Talkthrough cannot hear questions yet.

Hold to ask

and

Hold both keys together while you speak. Holding the first one alone gets the microphone ready sooner. The left-hand keys are used by many shortcuts, so the right-hand ones are safer.

Windows to skip

If the window in front has one of these words in its app name or title, holding the keys does nothing: nothing is recorded, captured or sent. Only the window in front is checked. The list starts with some password managers.
